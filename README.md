# Qiskit Learning Lab

A collection of small quantum-computing exercises built while learning Qiskit.

## Projects

| Project | What it demonstrates |
| --- | --- |
| [Quantum Hello World](examples/01-quantum-hello-world/quantum_hello_world.ipynb) | Creates a two-qubit Bell circuit with a Hadamard and controlled-X gate. |
| [Bell States](examples/02-bell-states/bell_states.ipynb) | Builds all four Bell-state circuits. |
| [Deutsch–Jozsa](examples/03-deutsch-jozsa/deutsch_jozsa.ipynb) | Uses a quantum oracle to distinguish constant and balanced functions. |

## Setup

1. Create and activate a Python virtual environment.
2. Install the dependencies:

   ```bash
   python -m pip install -r requirements.txt
   ```

3. Start Jupyter Lab:

   ```bash
   jupyter lab
   ```
